# Tableau Interactive Executive Dashboard

This folder contains the entry point to the interactive Tableau Public Dashboard for the **P2P Lending Credit Risk Analytics** project.

## Dashboard Preview & Core Modules

1. **Portfolio Overview:** Monitor total outstanding risk (Rp99.02B) and portfolio TWP90 default rate (25.38%).
2. **Sectoral Risk Distribution:** Granular drill-down of default exposure across employment categories (*Formal Employees & Gig Workers*).
3. **Financial Vulnerability Metrics:** Real-time distribution of Debt Service Ratio (DSR) and Limit Utilization Pct.
4. **Early Warning System (EWS) Matrix:** Automated 3-Tier risk classification for portfolio monitoring.
